# धनवृद्धि (DhanVriddhi) — फ्री निवेश कैलकुलेटर वेबसाइट

एक सिंगल-पेज, बिल्कुल फ्री, कोई बैकएंड न चाहने वाली फाइनेंस कैलकुलेटर वेबसाइट — SIP, Lumpsum, SWP, EMI, FD और Retirement Planner एक ही जगह। GitHub Pages पर सीधे डिप्लॉय हो जाती है।

## फाइलें
- `index.html` — पूरी वेबसाइट (HTML + CSS + JS एक ही फाइल में)
- `robots.txt` — सर्च इंजन को क्रॉल करने की अनुमति
- `sitemap.xml` — Google Search Console सबमिशन के लिए

## 1. GitHub Pages पर डिप्लॉय कैसे करें

1. GitHub पर एक नया रिपॉज़िटरी बनाएं, नाम रखें: `dhanvriddhi` (या कोई और नाम)।
2. `index.html`, `robots.txt`, `sitemap.xml` — तीनों फाइलें रिपॉज़िटरी के रूट में अपलोड/पुश करें।
3. रिपॉज़िटरी के **Settings → Pages** में जाएं।
4. **Source** में `main` ब्रांच और `/ (root)` फोल्डर चुनें, फिर **Save** करें।
5. कुछ मिनट में साइट यहां लाइव हो जाएगी: `https://आपका-यूज़रनेम.github.io/dhanvriddhi/`
6. `index.html`, `robots.txt` और `sitemap.xml` में जहाँ भी `your-username.github.io/dhanvriddhi` लिखा है, उसे अपने असली लिंक से बदल दें (Find & Replace कर लें)।

### कस्टम डोमेन (वैकल्पिक)
अगर आप `.com` या `.in` डोमेन खरीदते हैं (जैसे Namecheap, GoDaddy से), तो रिपॉज़िटरी में एक `CNAME` फाइल बनाकर उसमें अपना डोमेन लिखें (जैसे `dhanvriddhi.in`), और अपने डोमेन प्रोवाइडर के DNS सेटिंग्स में GitHub Pages के IP/CNAME रिकॉर्ड जोड़ें। कस्टम डोमेन Google पर ब्रांडिंग और भरोसे के लिहाज़ से बेहतर रहता है।

## 2. Google Search Console में सबमिट करें

1. https://search.google.com/search-console पर जाएं और अपनी साइट का URL जोड़ें (Ownership verify करने के लिए HTML मेटा टैग तरीका इस्तेमाल करें)।
2. **Sitemaps** सेक्शन में जाकर `sitemap.xml` सबमिट करें।
3. **URL Inspection** टूल से अपने होमपेज को "Request Indexing" करें।

## 3. Google AdSense से पैसे कमाना

1. जब साइट पर 20-30 दिन तक नियमित ट्रैफिक आने लगे (कम से कम 100+ रोज़ के विज़िटर होना बेहतर है), तब https://www.google.com/adsense पर अप्लाई करें।
2. अप्रूवल के बाद, `index.html` में जहाँ `<div class="ad-box">विज्ञापन स्थान...</div>` लिखा है, वहाँ AdSense का असली ad-unit कोड पेस्ट कर दें।
3. फाइनेंस/इन्वेस्टमेंट कीवर्ड्स पर आमतौर पर बाकी niches से ज़्यादा CPC मिलता है, इसलिए यह साइट मोनेटाइज़ेशन के लिहाज़ से अच्छी है।

## 4. एफिलिएट मार्केटिंग (एक्स्ट्रा इनकम)

आर्टिकल सेक्शन के नीचे या फूटर में Zerodha, Groww, Upstox जैसे ब्रोकर्स के एफिलिएट लिंक जोड़े जा सकते हैं (उनके पार्टनर प्रोग्राम में साइन अप करने के बाद)। जब कोई विज़िटर उस लिंक से अकाउंट खोलता है, तो आपको कमीशन मिलता है।

## 5. ट्रैफिक बढ़ाने के आसान तरीके

- **कंटेंट बढ़ाएं**: SIP, Lumpsum, EMI जैसे हर टॉपिक पर अलग-अलग ब्लॉग पोस्ट लिखें और साइट में जोड़ें — जितना ज़्यादा ओरिजिनल कंटेंट, उतनी बेहतर Google रैंकिंग।
- **Backlinks**: Quora, Reddit और फाइनेंस Facebook/Telegram ग्रुप्स में लोगों के सवालों के जवाब दें और वहां अपनी साइट का लिंक शेयर करें।
- **Social Media**: Instagram/YouTube पर छोटे फाइनेंस टिप्स वीडियो बनाकर बायो में लिंक डालें।
- **Page Speed**: यह साइट पहले से हल्की (lightweight) और तेज़ है — कोई भारी इमेज या लाइब्रेरी ऐड न करें, वरना गूगल रैंकिंग गिर सकती है।

## तकनीकी नोट
यह वेबसाइट pure HTML/CSS/JS में बनी है — कोई बैकएंड, डेटाबेस या बिल्ड-स्टेप नहीं चाहिए, इसलिए यह GitHub Pages (जो सिर्फ Static Sites होस्ट करता है) पर पूरी तरह काम करेगी। सारे कैलकुलेशन यूज़र के ब्राउज़र में ही JavaScript से होते हैं, इसलिए कोई यूज़र डेटा सर्वर पर नहीं जाता।
